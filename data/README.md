# Baseline data provenance

`gssub_baseline_ms640.csv` contains the presentation identifier, two relators,
nodes explored, and solution path length for 640 cases solved by the GS-Sub
one-million-node baseline associated with Fagan et al., *The Two-Hump Problem:
Bridging the Difficulty Gap in Mathematical Reinforcement Learning*
(arXiv:2606.21611).

This file was supplied to ACSolverES as external benchmark material. The local
repository history does not identify the individual who originally exported
the CSV, so Elliot Steffen and ACSolverES do not claim authorship of its
baseline measurements. The presentation family traces to Miller and Schupp
(1999), https://doi.org/10.1090/conm/250/03848, and the 1,190-case benchmark to
Shehper et al. (arXiv:2408.15332).
