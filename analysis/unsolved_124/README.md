# Unsolved 124 Data-to-Plot Pipeline

This folder turns the paired W&B export for the 124 unsolved presentations into
auditable CSV summaries and figures for the final paper and oral presentation.
The pipeline always orders Auto Dual GS first and Triple GS second, regardless
of their row order in the source export.

The presentation labels and relators are selected Miller-Schupp benchmark class
representatives; the paired algorithm measurements were generated by Elliot
Steffen. Full provenance and licensing details are in [`data/README.md`](data/README.md)
and the repository-level `THIRD_PARTY_NOTICES.md` and `LICENSE-DATA` files.

## Run

From the AC Solver Python environment:

```powershell
python unsolved124_pipeline.py
```

Alternatively, run `Unsolved_124_Plots.ipynb` from top to bottom.

## Validation

The pipeline requires exactly 124 matched presentation indices for each method.
It verifies matching labels, relators, starting lengths, and node budgets before
creating any result. Both supplied runs exhausted the one-million-node budget,
so node count and solve rate cannot distinguish the methods.

The main endpoint is the shortest total relator length reported at termination.
If a future export contains `minimum_total_length`, the pipeline uses it. The
current export omits that field, so it uses `final_total_length`, which is the
best state selected by these compact search backends.

## Outputs

The `outputs` folder contains:

- `processed_paired_results.csv`: one matched row per presentation.
- `algorithm_summary.csv`: reduction and best-length summaries, Auto Dual first.
- `head_to_head_summary.csv`: paired best-length wins and ties.
- `reduction_coverage_summary.csv`: overlap of presentations reduced.
- `triple_queue_summary.csv`: Triple GS expansion shares by move family.
- `artifact_manifest.json`: machine-readable inventory and key findings.
- `figures/paper`: compact PNG and vector PDF figures.
- `figures/slides`: 16:9 PNG and vector PDF figures with larger text.

## Recommended Figures

For the oral presentation, use `reduction_coverage` to communicate that Triple
GS reduced all 22 presentations reduced by Auto Dual plus 6 additional cases.
The `paired_best_total_length` figure supports the stronger paired statement:
Triple GS was shorter on 9 presentations, tied on 115, and was never worse.

For the paper, use `paired_best_total_length`, `reduction_magnitude`, and the
`reduced_cases_matrix`. The `triple_queue_mix` figure is a methods diagnostic;
it should not be interpreted as a comparison with Auto Dual because Auto Dual
uses one combined queue rather than separate substitution and automorphism
queues.

Runtime is intentionally not plotted.
